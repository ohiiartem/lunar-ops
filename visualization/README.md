# Визуализация LOLA и JPL Horizons

Открой папку проекта в VS Code через **File → Open Folder**, затем выбери **Terminal → New Terminal**. Для запуска нужен Node.js 22.12+ из ветки 22 или более новая поддерживаемая версия.

```sh
npm ci
npm run dev
```

Открой адрес из терминала, обычно http://localhost:5173/. Остановить локальный сервер можно через Ctrl+C. Папки `public/data/R01` и `public/data/R11` уже содержат карты и результаты.

## Первый тест

На глобусе выбери R01. В режиме **Sky** откроется небо на 17 ноября 2026 года, 23:00 UTC. Земля выше плоскости 0° на 0,02°, а местный горизонт в её направлении находится на высоте около 1,28°. Перейди в **3D Terrain** и нажми на маркер или поверхность, чтобы открыть **Surface View**. В панораме можно повернуться на 360° мышью или клавишами со стрелками. Точка наблюдения остаётся на выбранной посадочной площадке.

Ползунки дня и времени, кнопки +1/+5 дней и воспроизведение управляют всеми видами и графиками в **Scientific Analysis**. Показания видимости обновляются по 30-минутным отсчётам. Положение маркеров между отсчётами интерполируется. Оси панорамы показывают азимут и высоту в градусах. Масштаб высоты увеличен для читаемости.

```sh
npm test
npm run build
```

Тесты проверяют оба сценария и перевод азимута в координаты полярной карты. Сборка создаёт `dist/`.

## Данные

Сетка высот 512 × 512 (512 КиБ) загружается при наведении на карту или открытии 3D. В режиме разработки Vite перенаправляет запросы `/api/timeseries` к FastAPI на `127.0.0.1:8000`. Без API сайт использует сохранённые ответы в `public/data/R01/sky.json` и `public/data/R11/sky.json`. В статической сборке используются эти сохранённые ответы. Источник указан в деталях площадки. Данные загружаются при выборе площадки. Во время воспроизведения камера, объекты и графики используют уже загруженные данные.

Для обновления сохранённых ответов запусти с работающим FastAPI:

```sh
python3 scripts/export_sky.py
```

Чтобы обновить карты и сетки после пересчёта LOLA, в корне проекта запусти:

```sh
python3 -m pip install numpy pillow
python3 scripts/export_data.py ../LOLA-data/data
```

Профиль видимости ограничен площадью исходного GeoTIFF. Углы Horizons рассчитаны для наблюдателя на опорной сфере. Рельеф в 3D построен из облегчённой сетки, стрелки показывают направление. Локальный направленный свет следует за Солнцем. Видимость определяется по профилю горизонта. Для Солнца используется верхний край диска, для Земли — центр.

Глобус использует цветовую карту LROC и карту высот NASA для визуального микрорельефа. При выборе площадки камера приближается к её координатам и открывает локальный вид.

[Карты глобуса · NASA SVS CGI Moon Kit](https://svs.gsfc.nasa.gov/4720)

## Солнце, Земля и Луна

Открой **Solar system**, чтобы увидеть траектории Земли вокруг Солнца и Луны вокруг Земли. Общая шкала времени управляет обзором. Клик по Луне, её подписи или карточке открывает глобус с фокусом на южный полюс. Раздел **Moon markers** содержит все метки проекта, включая оба полюса, R01, R11 и шесть посадок Apollo. Ориентиры с обратной стороны доступны через список и при вращении глобуса.

`public/data/system-orbits.json` хранит геометрические векторы DE441 в эклиптической системе J2000, в километрах и по UTC. Для Земли векторы заданы относительно Солнца, по одному отсчёту в сутки с 7 ноября 2026 года до 8 ноября 2027 года. Для Луны векторы заданы относительно Земли, каждые три часа с 7 ноября до 7 декабря 2026 года. В сцене масштабы двух траекторий и размеров тел подобраны для читаемости. Углы и видимость на площадке по-прежнему берутся из отдельных таблиц наблюдателя. Для повторного экспорта используется `scripts/export_orbits.py`. [Документация JPL Horizons](https://ssd-api.jpl.nasa.gov/doc/horizons.html)

## Выбор точки и плавность

Нажмите метку R01 или R11 на глобусе. Соединительная линия указывает на координаты площадки. Метки разведены для удобства выбора близких точек южного полюса. Клик по самой точке также открывает площадку. Боковые кнопки поддерживают выбор с клавиатуры.

Переход камеры рассчитывается по времени и длится 1,1 секунды. Инерция вращения использует время между кадрами. Автоматический тест проверяет одинаковое затухание за секунду на 60, 120 и 144 Гц. Фактическая частота кадров зависит от устройства. Рендеринг приостанавливается после остановки камеры, в скрытой вкладке и для закрытого глобуса. Поддерживается системная настройка уменьшения движения.

2D-карту можно увеличивать колёсиком или кнопками +/− и перемещать мышью. Кнопка «Сброс» возвращает исходный масштаб. В 3D работают вращение, приближение и перемещение камеры.

Локальная сетка использует высоты над сферой 1737400 м, кадр MOON_ME/DE421. Численное совмещение с углами Horizons DE441 остаётся приближением.

Визуальное направление задано примером https://galaxy3d.ru/solnechnaya-sistema-3d.html — вращение объекта и выбор точки на нём.

## LUNAR OPS

Выбери R01 или R11 на глобусе. Панель площадки показывает координаты,
высоту грунта и разрешение данных. В карте есть цвет высоты и отмывка.
Для чтения высоты наведи курсор на карту. Видимые размеры измеряются в
метрах полярной сетки. 3D использует ту же сетку 512 × 512, по умолчанию 1×.
Переключатели 2× и 5× увеличивают рельеф для осмотра. Стрелки сохраняют
астрономические углы.

Панель анализа показывает траектории высоты объектов и порог LOLA,
количество видимых отсчётов в двух моделях и интервалы по доступным
отсчётам. Момент перехода можно определить с точностью до периода отсчётов.
Высоты заданы над сферой радиусом 1737,4 км. Данные LOLA привязаны к
MOON_ME / DE421. Horizons использует MEAN_ME / DE441 с исходными
координатами наблюдателя на уровне сферы. Местный горизонт рассчитан с
мачтой 2 м над грунтом. Численное совмещение версий ME и высот наблюдателя
используется как приближение. Расчёт ограничен покрытием DEM.

### Пересборка данных в терминале

Укажи путь к папке с двумя оригиналами NASA и папке с четырьмя исходными
TXT Horizons. Python-окружение требует numpy, pillow, rasterio и pyproj.

```sh
python3 -m pip install numpy pillow rasterio pyproj
for n in 01 11; do
  python3 scripts/prepare_lola.py "R$n" "../LOLA-data/source/Site${n}_final_adj_5mpp_surf.tif" "processed/R$n" --width-m 5000 || exit
done
python3 scripts/compare_visibility.py --horizons "$HOME/Downloads" --data processed
python3 scripts/export_data.py processed
```

Для браузера подготовлены WebP, компактный JSON, исходный профиль CSV
и упакованные высоты. Обзор 256 и сетка 1024 доступны как результаты
экспорта. Интерактивный режим использует сетку 512. Сетка 1024 получена
интерполяцией в окне 5 км. Она не повышает разрешение исходного DEM.
