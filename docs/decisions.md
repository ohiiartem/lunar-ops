# Решения по расчётному ядру (записать в README)

| Вопрос | Решение | Почему |
|---|---|---|
| Солнце «над горизонтом» | верхний край: высота центра + угловой радиус (около 0,27°, радиус 695 700 км) | так считает и сам Horizons; тест сверяет с его флагом `*` на всех 145 шагах |
| Земля «видна» | по центру диска (по умолчанию); `earth_limb=True` считает по верхнему краю (угловой радиус около 0,95°, радиус 6371 км) | Земля шириной около 1,8°, у горизонта выбор меняет окна; оба варианта выводятся, судьям говорим «геометрическая видимость» |
| Горизонт | профиль рельефа LOLA (угол от местной горизонтальной плоскости площадки) или 0° без рельефа | совпадает с топоцентрической высотой Horizons |
| Окно | от первого шага, где тело выше горизонта, до первого шага, где ниже; шаг таблицы 10 мин | без интерполяции между шагами; окна на краю данных помечены `open_start`/`open_end` |
| Время | UT, как в таблице Horizons | |
| Формат CSV | 12 значений в строке, колонки по позиции; заголовок игнорируется; az/el сверяются с вектором east/north/up | в заголовке 13 имён, он не совпадает со строками |

## Ограничения (в README и на слайд)
- Профиль рельефа считается только по тайлу LOLA (8–15 км); дальние хребты не учтены, поэтому горизонт может быть только занижен.
- В самих CSV площадка не указана, она задаётся именем файла (`sun_R23.csv`). Данные покрывают один день (14.11.2026 UT).
- «Плоский горизонт» (0°) и профиль рельефа не одно и то же: с высокой точки рельеф может уходить ниже 0° и открывать Солнце, а гребень рядом закрывает. Рельеф добавляет и убирает время.
- Геометрия только: качество радиосвязи и энергия панелей не считаются.

## Проверка входных файлов Horizons (14.11.2026, один день, шаг 10 мин)
- Файлы: `data/horizons/sun_<ID>.csv`, `earth_<ID>.csv` для R01, R11, R23. Они соответствуют площадкам: подсолнечная долгота из азимутов получается 126,6° для всех трёх, подземная −1,2…−1,3° (тест `test_files_match_the_sites`).
- Старые файлы `telemetry_output (2).csv` и `telemetry_output_earth.csv` относятся к другой площадке (долгота около +4,8°), к R23 они не относятся. Расчёты по ним не использовать.
- `telemetry_output.csv` (Солнце) посчитан с Земли, не использовать.

| R11 | горизонт 0° / рельеф | 24,17 / 24,17 | 0 / 0 | 0 / 0 |
| R23 | горизонт 0° | 4,83 | 9,5 | 4,83 (19:20–00:10) |
| R23 | рельеф | 14,67 | 0 | 0 |

- R01 и R11: Земля на высоте −5° и −4°, то есть под горизонтом и без рельефа.
- R23: Земля поднимается до +0,45°, а рельеф в её азимуте около 4,7° из-за выступа на 25 м выше точки на расстоянии около 300 м. Вывод устойчив: при смещении точки на ±20 м и высоте наблюдателя до 10 м горизонт там не ниже 2,8°.
- R23, Солнце: Horizons ставит флаг `*` на всех 145 шагах, хотя верхний край Солнца выше 0° только в 29. Гипотеза: при расчёте введена высота площадки (4,784 км), и флаг считается относительно линии горизонта с учётом понижения, а высоты (az/el) даны от местной горизонтали. Нужно подтвердить, какую высоту ввели. Мы используем высоту и азимут, не флаг.
- «Горизонт 0°» для высокой площадки не равен горизонту сферы (понижение около −4° на 4,8 км). Показывать судьям как «плоскость без рельефа».
- Один день не показывает типичной картины: общих окон нет ни у одной площадки. Нужно 14+ суток.
